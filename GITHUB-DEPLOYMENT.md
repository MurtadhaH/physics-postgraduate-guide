# GitHub Pages Deployment

This folder is ready to publish as a static GitHub Pages site.

## Recommended repository settings

1. Create a repository for the public website.
2. Upload the contents of this folder to the repository root.
3. Keep `COPYRIGHT.md` and the copyright notices in the source files.
4. Do **not** add an open-source license unless you intentionally want to grant reuse rights.
5. In GitHub repository settings, enable Pages from the branch/root used for this site.
6. Keep your full development backups locally and preserve your Git commit history.

## Ownership markers included

- `COPYRIGHT.md`
- author and copyright metadata in `index.html`
- source-file copyright headers
- visible footer attribution
- professional repository `README.md`

## Important

A static website must send its HTML, CSS and JavaScript to the visitor's browser. These measures make authorship and rights explicit; they do not make frontend code technically invisible.
